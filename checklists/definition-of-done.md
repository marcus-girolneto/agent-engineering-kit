# Definition of done

- The requested behavior and failure cases are implemented; assumptions are documented.
- Focused behavior tests and `kit check` pass, or each incomplete check is explicitly reported.
- Dependency changes have a reviewed lockfile diff and a successful advisory audit.
- New inputs, object access and data persistence have been reviewed against the threat model.
- Docs, examples and public contracts match the implementation.
- The final diff contains no unrelated edits, credentials or unexplained generated files.
- The handoff identifies limitations and remaining actions. Commit or publish only within the authorized scope.

A clean gate is necessary evidence, not a security certification or permission to deploy.
